# RoomJam

RoomJam is a real time collaboration workspace where users can join shared rooms  to code together,  brainstorm on live whiteboard, take shared notes, ans collaborate seamlessly.

## Tech Stack

## FrontEnd

- React 
- Tailwind CSS
- Monaco Editor
- ExcaliDraw (For WhiteBoard)
- TipTap Editor


## BackEnd

- FastAPI
- WebSockets
- Redis
- PostgreSQL

## Real-Time Collaboration

- Yjs
- y-websocket
- Socket.IO

## Storage and Authentication

- SupaBase
- JWT Authentication
